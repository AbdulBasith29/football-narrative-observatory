# Agent Guidelines

## Git Workflow
When working on features in this repository, you MUST follow this workflow:
1. Ensure `main` is up to date.
2. Create a new feature branch: `feature/<feature-name>`.
3. NEVER commit directly to `main`.
4. Make coherent, meaningful commits on the feature branch.
5. Run all relevant tests before completion.
6. Open a Pull Request targeting `main`.
7. DO NOT merge the PR. Leave it for human review.
