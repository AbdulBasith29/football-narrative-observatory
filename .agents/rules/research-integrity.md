# Research Integrity & Invariants

These invariants are permanent, non-negotiable constraints governing the Football Narrative Observatory.

## 1. Frozen Methodology Protection
- **Methodology Immutability**: Never silently alter, re-interpret, or relax methodology defined in `docs/` or `config/`.
- **Human Approval**: Any proposed modification to research questions, sampling rules, window definitions, or narrative taxonomy requires explicit human approval before code changes.
- **Scope Discipline**: Never begin a subsequent pipeline phase (e.g., video metadata ingestion, comment harvesting, NLP) merely because the current phase appears functional.

## 2. Experimental & Environment Isolation
- **Frame Isolation**: `RESEARCH` runs must NEVER consume `PIPELINE_PILOT` frames. Pilot frames exist solely to validate pipeline mechanics with minimal quota.
- **Data Contamination Prevention**: Data generated by `INTEGRATION_TEST` or pilot validation runs must never contaminate research tables or be mixed with analytical datasets. Target `FOOTBALL_NARRATIVE_TEST` for tests and `FOOTBALL_NARRATIVE_DEV` for pipeline development.
- **Frame Purpose Enforcement**: Any query selecting frames for pipeline verification must explicitly filter `WHERE frame_purpose = 'PIPELINE_PILOT'`.

## 3. Epistemic Scope
- **Corpus Boundaries**: Never claim or infer that observed YouTube sentiment represents "global football-fan opinion". All analytical assertions must be strictly bounded to: *"comments within the sampled YouTube corpus during the defined event windows"*.
- **Quality Over Claims**: Avoid unsupported claims (e.g., "production-grade"). Describe systems accurately as reproducible research pipelines and operational discovery services.
